## Objective of the Lab
In this lab, you will learn to get information about the current connection statistics of TCP. 

TCP enables two hosts to establish a connection and exchange streams of data. Instructions

### STEP 1
On the taskbar, click the Start menu and then click Windows PowerShell to open the Windows PowerShell window

### STEP 2
In the Windows PowerShell window, enter the following command to obtain information about the current connection statistics of TCP:
```bash
Get-NetTCPConnection
```
Where, the Get-NetTCPConnection cmdlet is used to view TCP connection properties such as local or remote IP address, local or remote port, and connection state.
